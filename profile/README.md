# VERIS

**Verified Election via Resilient Immutable System**

VERIS is a blockchain protocol under development for verifiable elections. Once an election starts, its rules cannot be changed by any authority. Votes can be audited and counted independently by anyone, and every voter can check that their own vote was recorded and counted correctly. The project also aims to lower election costs and to demonstrate the protocol's scalability with a 1:1-scale election simulation.

VERIS, doğrulanabilir seçimler için geliştirilmekte olan bir blockchain protokolüdür. Seçim başladıktan sonra kurallar hiçbir otorite tarafından değiştirilemez, oylar herkes tarafından bağımsız olarak denetlenip sayılabilir ve her seçmen kendi oyunun doğru sayıldığını doğrulayabilir.

## Status / Durum

The project is in **closed development**. It is being prepared for the TÜBİTAK 2204-A competition, so the source code is not public yet. The plan is to move to semi-open development, and to full open source after the competition's final application date.

Proje **kapalı geliştirme** aşamasındadır. TÜBİTAK 2204-A yarışması için hazırlandığından kaynak kod henüz herkese açık değildir. Planlanan süreç: yarı-açık geliştirme, ardından yarışma son başvuru tarihinden sonra tam açık kaynak.

All data shown on the project sites is experimental and for testing. It has no connection to any official election.
